# 字雀麻将馆

一个免注册的线上朋友局麻将馆，支持字雀文字麻将、川麻与京麻。

玩法借鉴《白色失明文字麻将》。本项目是独立制作的非官方线上版本，与原作方无隶属或授权关系。

## 已有功能

- 免注册轻登录，入座后提示确认昵称，名字和头像颜色保存在当前设备
- 四位房号、邀请链接与扫码入座二维码
- 2—4 人实时房间、摸牌、抢吃任意牌友的弃牌、出牌、胡牌、再来一局
- 吃牌后当轮不能摸牌，必须直接出牌
- 胡牌需由申请者之外的牌友投票，赞成过半才通过
- 144 张牌按口语使用频率分布，提高连接字、常用动词与代词的出现率
- 川麻血战到底：108 张牌、换三张、定缺、碰杠、七对与服务端胡牌判定
- 京麻吃碰提：136 张牌、上滚混儿、吃碰杠、七对，吃碰明杠后仅可自摸
- 麻将操作按“胡 > 碰/杠 > 吃”处理，低优先级操作会等待高优先级牌友选择或过牌
- 朋友局简化积分：保留自摸、点炮与京麻点炮包付，暂不展开各牌馆差异较大的完整番种表
- 刷新或短暂断线后自动找回牌桌
- 手机和桌面端响应式界面

## 项目结构

- `app/`：React/vinext 全栈版本
- `github-pages/`：GitHub Pages 静态前端入口
- `aliyun-function/`：阿里云函数计算 + 表格存储联机后端
- `.github/workflows/pages.yml`：GitHub Pages 自动发布流程

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

构建完整版本：

```bash
npm run build
```

构建 GitHub Pages 前端：

```bash
VITE_ZIQUE_API_BASE=https://your-api.example.com npm run build:pages
```

## GitHub Pages

仓库变量 `ZIQUE_API_BASE` 用于指定联机 API 地址。工作流会在 `main` 分支更新时构建并发布静态前端。

## 阿里云后端

部署说明见 [`aliyun-function/README.md`](aliyun-function/README.md)。函数通过阿里云函数角色取得临时凭证，不需要把 AccessKey 写进代码或 GitHub。
